## 📚 Problem Solutions Included

### String & Character Problems
- **Gray Code** - Generate Gray code sequences
- **Anagram Palindrome** - Check if a string can form a palindrome
- **Next Smallest Palindrome** - Find the next palindromic number

### Array & Subarray Problems
- **Segregate 0s and 1s** - Partition array with two-pointer technique
- **Sum of Subarray Minimums** - Calculate sum of minimum elements in all subarrays
- **Count Subarrays with Given XOR** - Find subarrays with specific XOR value using hashing
- **Pythagorean Triplet** - Identify Pythagorean triplets in arrays

### Tree Problems
- **Minimum Height Roots** - Find nodes that minimize tree height when used as root
- **Distribute Candies** - Calculate minimum moves to distribute candies in a tree

### Dynamic Programming & Combinatorics
- **Consecutive 1's Not Allowed** - Count binary strings without consecutive 1s using DP

## 📖 Notable Solutions

### 1. Gray Code (`Gray Code.py`)
- Generates Gray code sequences where consecutive numbers differ by one bit
- Uses recursive approach with string manipulation
- Time Complexity: O(2^n)

### 2. Count Subarrays with Given XOR (`Count Subarrays with given XOR.py`)
- Uses XOR prefix and hash map technique
- Efficiently counts subarrays with specific XOR value
- Time Complexity: O(n)

### 3. Minimum Height Roots (`Minimum height roots.py`)
- Implements topological approach using BFS
- Finds optimal root nodes to minimize tree height
- Time Complexity: O(V + E)

### 4. Distribute Candies (`Distribute Candies.py`)
- Uses DFS tree traversal
- Calculates minimum moves for candy distribution
- Time Complexity: O(n)
